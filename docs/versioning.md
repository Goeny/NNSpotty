# Versioning en codenames

## SemVer beleid
We gebruiken Semantic Versioning:
- `MAJOR.MINOR.PATCH`
- Voor development starten we op `0.0.1`.
- De eerste stabiele productie-release wordt `1.0.0`.

## Codenaambeleid
Elke release krijgt een codenaam op basis van een interessante automodel-variant.

Voorbeelden van geschikte stijl:
- Delta Integrale
- Skyline GT-R
- M3 CSL
- 911 GT3 RS
- Alpine A110 S

## Actuele release
- **Versie:** `0.0.1`
- **Codenaam:** `Delta Integrale`
- **Status:** Initiële documentatiefase

## Releaseadministratie
Bij elke versie-upgrade:
1. Update deze file met nieuwe versie + codenaam.
2. Update [README.md](../README.md) met actuele status.
3. Voeg beslissing/rationale toe in [second-brain.md](./second-brain.md).
